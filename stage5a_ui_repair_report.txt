UI ROOT CAUSE:
The `CashBooksView.tsx` component was written using Tailwind CSS classes (e.g., `bg-white`, `border-gray-200`, `grid-cols-5`). However, the project does not have Tailwind CSS installed (`package.json` has no `tailwindcss` dependency and `tailwind.config.ts` does not exist). The Pre-Audit visual system relies on raw CSS / inline React `style={{ ... }}` objects. Because Tailwind was missing, the classes did nothing, causing the report to render as unstyled, plain HTML.
